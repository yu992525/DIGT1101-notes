# DIGT1101 Midterm Study Plan

**Midterm scope:** Weeks 1–5 lectures + Labs 01–08.
**Method:** one small step at a time → explain → quick-check questions → write the notes together → commit.

Tick a box when the step's notes are written *and* the quick-check answers were right.

## Part A — Foundations
- [ ] **01** Variables, data types, casting, `input()` / `print()`, f-strings → [notes/01-variables-io.md](notes/01-variables-io.md)
- [ ] **02** Arithmetic operators & precedence (`/` `//` `%` `**`)
- [ ] **03** Strings: indexing, slicing, methods, `in`
- [ ] **04** Comparison & logical operators, `if` / `elif` / `else` *(Lec 05)*
- [ ] **05** `while` loops, input validation, `break` / `continue` *(Lec 05)*
- [ ] **06** `for` loops, `range`, nested loops *(Lec 06)*
- [ ] **07** Lists: methods, alias vs copy, `sort()` vs `sorted()`
- [ ] **08** Functions: `def`, parameters, `return`, keyword/default args, scope *(Lec 04)*

## Part B — The patterns (where most exam marks are)
- [ ] **09** The 4-step method + accumulator (count / sum / product / list)
- [ ] **10** Search for a counterexample ("fail inside, pass after"), remove duplicates
- [ ] **11** Dictionaries: nested access, counting with `.get(x, 0)`
- [ ] **12** 2D lists: rows vs columns, comma input with `split` / `map`, pad & truncate
- [ ] **13** Fibonacci: loop version and recursive version

## Part C — Practice
- [ ] **14** Work through the [Week 7 lab questions](labs/week07-lab-questions.md) yourself (no peeking)
- [ ] **15** Mock midterm + review of mistakes
- [ ] **16** Build the final one-page aid sheet

## Personal traps to watch (from my review sheets)
- Naming variables after built-ins (`min`, `max`, `sum`, `list`, `str`, `type`, `len`)
- `=` vs `==`
